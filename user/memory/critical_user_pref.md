# Preferencias Críticas

1. **Respuestas Sintéticas y Prácticas**: Evitar rodeos. Presentar soluciones estructuradas y accionables.
2. **Prioridad a Micro-Metas**: Dividir grandes tareas (como ensayos o proyectos) en sesiones concentradas de 15 a 30 minutos.
3. **Reportes Periódicos**: Preparar resúmenes semanales (como las recomendaciones de trabajo en LinkedIn los sábados).
4. **Fallback Inteligente**: Ante falta de datos o falla de APIs externas, ofrecer sugerencias estructuradas en lugar de errores crudos.
